## Why this is a packet and not an execution

The 20-10 session adopted D18 and the migration D1–D5 under the blanket directive because those plans had **recorded defaults** the directive could ratify. This plan §9 explicitly says each M2M answer "cannot be inferred" from the code — and three of the four (D2–D4) are data-model shapes (event fields, projection rows, journal volume) that compound if guessed wrong, exactly the class the owner's own AGENTS philosophy parks ("a wrong data model costs months"). The recommendation column above pre-stages the reasoning so the owner's tick is one word per row; **no W1/W2 code lands before that tick** (the TODO row's Verify condition is unchanged).
