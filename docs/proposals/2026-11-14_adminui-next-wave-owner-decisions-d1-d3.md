## Why this is a packet and not an execution

All three answers compound: D1 ships an "act as user" security surface, D2 changes what a published module must expose next train, D3 orders the next ~2 waves of admin work. The plan §7 explicitly gates them ("must not start without an answer to section 7"). The M2M packet precedent applies verbatim: recommendations pre-staged, **no panel code for impersonation, bots, sessions or rename lands before the tick**; M06 (import/export) and everything else in the current plan is unaffected — it needs none of these answers.
