The one gap: git-hooks.nix

The project has 187 root lint issues and 9 linters enabled, but nothing runs automatically on commit. A bad commit can land without any local quality gate. CI catches it eventually, but the inner-loop is slow.

Fix: Add git-hooks.nix input and wire into devShells.default: 

inputs = {
  # ... existing inputs ...
  git-hooks = {
    url = "github:cachix/git-hooks.nix";
    inputs.nixpkgs.follows = "nixpkgs";
  };
};

# In perSystem:
devShells.default = pkgs.mkShellNoCC {
  packages = [ /* existing */ ];
  shellHook = config.pre-commit.installationHook;
};

pre-commit = {
  check.enable = true;
  hooks = {
    treefmt.enable = true;     # runs gofmt + templ + nixfmt
    golangci-lint = {
      enable = true;
      entry = "golangci-lint run";
      pass_filenames = false;
    };
    govet.enable = true;
  };
};

This activates quality gates on every nix develop + git commit.
