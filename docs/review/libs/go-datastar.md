## What the library is

Server-side DataStar protocol vocabulary for Go — the opinionated alternative to the official `starfederation/datastar-go` (v1.2.2): patches are **first-class values** (`Patch` → `sse.Event`), not methods on a live connection. Root = patch constructors + inbound signal decoding + fluent `Response` + embedded-JS serving; `broadcast` = fan-out hub (sharing, replay, heartbeats); `static` = the embedded datastar JS client (versioned by the JS release line — currently **v1.0.4** — while its Go module rides a separate, newer-numbered tag train); `datastartest` = E2E SSE assertions.
