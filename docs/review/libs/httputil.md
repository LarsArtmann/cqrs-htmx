## What the library is

The LarsArtmann HTTP middleware toolkit: CSRF (nosurf-based, RFC 10008 QUERY-aware since v1.9.0), keyed rate limiting, per-request CSP nonces (with a `CSPBuilder` seam for custom policies), security headers, server lifecycle (`NewServer` with validated `ServerConfig`, TLS, shutdown), client-IP/trusted proxies, CORS, compression/decompression, request/body limits, request IDs, logging, metrics, Server-Timing (submodule), i18n language negotiation, K8s health endpoints, `MiddlewareStack` composition with validation, and an `httpspec` behavioral compliance suite. cqrs-htmx's CSRF/Server-Timing/rate-limit re-exports are thin deprecated aliases over this library (v5 removes them; internal modules already import httputil directly — 0 deprecated-alias uses re-verified 2026-11-22).
