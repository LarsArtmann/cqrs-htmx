## What the library is

Typed error families (Rejection / Conflict / Transient / Corruption / Infrastructure / Orchestration) with machine-readable codes, context, classification/registry, retryability predicates, audience-aware default messages, classified logging, CLI exit-code handling, and HTTP status mapping. In this repo `errors.New`/`fmt.Errorf`/`errors.Join` are **banned in non-test code** (AST scanner `scripts/checks/errorfamily_scanner.go`, wired into flake.nix:1179 + ci.yml:1213); every error flows through this library or its `go-cqrs-lite/event` re-exports. Posture re-derived 2026-11-22: the only 9 remaining stdlib constructors in tree are all in `openapi/validate.go` — the scanner-exempt, stdlib-only-by-design `openapi` package (scanner skips `openapi`/`cmd`/`examples`/`e2e`/`vendor`, errorfamily_scanner.go:84; the scanner walks the repo tree from `.`, so nested modules like legalparty-model are covered by the root pass). Commit 290d3a25 (2026-11-07) even purged a banned `fmt.Errorf` from the sibling `reexport_scanner.go` itself.
