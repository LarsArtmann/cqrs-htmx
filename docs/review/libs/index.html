02Fleet Issues

Important

Silent SSE drops are unobserved

go-sse: WithOnDrop / BroadcasterHealth — 0 prod uses

Slow SSE consumers are dropped silently by design; the library ships exactly the hooks (drop callback, subscriber health) that would make drops visible. The adminui sync indicator and dashboardui are the natural consumers.

Fix Wire WithOnDrop (log + optional metric) at the root Broadcaster seam; surface BroadcasterHealth beside the sync indicators.
Important

Health dashboard not CSP-nonce-safe through the bridge

health/dashboard.go — WithNonce unthreaded

The repo's own recommended middleware stack is nonce-CSP-first, but health.NewDashboard forwards only WithTitle; the dashboard's inline scripts need the nonce option under that same stack.

Fix Accept and forward a nonce (or WithNonceExtractor) in the bridge's NewDashboard.
Nice to have

Dogfooding polish: partial-render helpers & stack validation

RenderPartialOrFull / OOBHTML / httputil.NewMiddlewareStack

RenderPartialOrFull and OOBHTML have zero internal-module uses (tests + docs only), and the recommended security chains are built by hand instead of through httputil's validated MiddlewareStack.
