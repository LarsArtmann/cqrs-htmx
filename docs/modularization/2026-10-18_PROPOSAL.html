Watch item W1 — the root package, not the root module

Package cqrshtmx (repo root) carries 57 production files / ~8.0k LOC / 267 exported top-level symbols — past every god-package rule of thumb (15+ files, 30+ symbols). Cohesion clusters exist (options/sync/sse/htmx/event/projection/csrf prefixes) and the escape valve is already in active use: openapi/ and transport/ are subpackages. Verdict: keep in v4 — the single-import surface is the product's DX, and splitting it breaks every consumer's import lines for zero dependency-graph gain (no cycle, no weight difference — the subpackages would still ship in the same module). Discipline going forward: genuinely orthogonal NEW surfaces (the pattern transport/ set) go to new subpackages; nothing new grows in the flat package without a prefix-cluster justification. Revisit only at a v5 boundary alongside the SSE-re-export removals.
