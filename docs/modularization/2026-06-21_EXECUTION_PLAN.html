Before structural refactoring, fix the 8 critical issues found in the code review (docs/reviews/2026-06-21_19-21_full-code-review.html). Tier 1Step 1

Extract domain/ package

Files to move: user.go, id.go, email.go, credential.go, external_account.go, domain errors from errors.go

// ... etc for all moved types
Verify: GOWORK=off go build ./... + GOWORK=off go test ./... -race -count=1 in usermgmt. Zero import path changes for consumers.

Rollback: git revert HEAD — single commit restores flat package.

Extract authz/ package

Files to move: authz_types.go, authz_policies.go, authz_roles.go

Tier 2Step 3

Extract store/ package

Tier 2Step 4

Extract eventsource/ package

Files to move: All 35 es_*.go files (User, Bot, Membership, Tenant aggregates + projections + setup + upcasters + migration)

Target structure:

usermgmt/eventsource/
├── user/          # User aggregate: es_state, es_decide, es_dispatch, etc.
├── bot/           # Bot aggregate: es_bot_*.go
├── membership/    # Membership aggregate: es_membership_*.go
├── tenant/        # Tenant aggregate: es_tenant_*.go
├── readmodel.go   # UserReadModel (cross-aggregate)
├── casbin_projection.go
├── setup.go       # EventSourcedConfig, StartProjections
├── upcaster.go
└── migration.go

Depends on: domain/ + authz/ (for CasbinProjection).

Re-export from root: RegisterCommands, EventSourcedConfig, StartProjections, UserDecider.

Verify: go build ./... + full test suite with -race. This is the largest step — expect ~30 min of import path fixing.

T3Tier 3 — Subsystems (Complete the Graph)

Tier 3Step 5

Extract webauthn/, oauth2/, totp/ packages

WebAuthn: webauthn_adapter.go, webauthn_session.go, webauthn_service.go → usermgmt/webauthn/

OAuth2: oauth2.go, service_oauth2.go, oauth2_http.go → usermgmt/oauth2/

TOTP: totp.go → usermgmt/totp/

Each subsystem service is embedded into the root Service struct. Methods are promoted via Go embedding (preserves flat API). Each depends on domain/ only.

Fix while moving: WebAuthn UV flag hardcoding (H3), OAuth2 token exchange error mapping (H2), TOTP replay protection (L3).

Verify: go build ./... + targeted tests for each subsystem with -race

T4Tier 4 — Polish

Tier 4Step 6

Extract httpapi/ + internal/

HTTP: http.go, verification_totp_http.go, credential_http.go, import/export endpoints → usermgmt/httpapi/

Internal: crypto.go, random.go, eviction.go → usermgmt/internal/

The internal/ package makes these truly opaque — no consumer can import them.

Verify: go build ./... + full test suite
