## e) WHAT WE SHOULD IMPROVE

### Process improvements

1. **Always verify with `go list -m all`** after dep bumps — `go.mod` declarations ≠ actual MVS selections
2. **Always run `nix run .#build` / `nix run .#lint` / `nix run .#test`** — never raw `go build`/`golangci-lint`
3. **Check coverage before AND after** dep upgrades to catch silent regressions

### Architecture improvements

4. **Read models need persistence** — all 4 are in-memory maps, data lost on restart. `storage.SQLViewStore` is the v3.1.0 answer
5. **Hand-wired infrastructure** — 270 LOC of manual event store + bus + projection setup that `stack/sqlite.New()` replaces in 1 line
6. **No graceful shutdown** — `Service.Stop()` only stops eviction goroutines. No `Close()` for the bus/store lifecycle
7. **closeBus pattern is fragile** — type-asserts `io.Closer` at 7 error-return sites. `stack.MultiCloser` would be cleaner

### Testing improvements

8. **Coverage investigation needed** — usermgmt dropped from 88.7% → 82.3%
9. **SQLite tests don't use WAL** — `OptimizeSQLiteDB` tested but not applied in test helpers
10. **No integration test for SQL event store + session store sharing a SQLite connection**

## Update 2026-06-25 21:00 — Coverage Mystery SOLVED

**Root cause: The 88.7% was stale, not a regression.**

The 88.7% figure was last measured at commit `d2b43c8` (2026-06-17) when usermgmt had **39 non-test files**. Since then, **36 new non-test files** were added (Bot, Tenant, Membership, OAuth2, Impersonation, API tokens, migration, upcaster, eviction, etc.) — nearly doubling the codebase. These new features brought partial coverage, naturally diluting the percentage.

**Evidence:**

- `d2b43c8` (June 17): 39 non-test Go files → 88.7%
- Current (June 25): 75 non-test Go files → 82.3%
- The v3.1.0 upgrade changed ZERO APIs and added only `OptimizeSQLiteDB` (15 LOC + test)

**Verdict: NOT a regression.** The coverage percentage is correct at 82.3%. The prior 88.7% was simply never updated as new code was added. The biggest uncovered areas are new feature code: `oauth2_http.go` (5.4%), `es_migration.go` (0%), `es_tenant_decide.go` (76.9%), `es_casbin_projection.go` (58.8%).
