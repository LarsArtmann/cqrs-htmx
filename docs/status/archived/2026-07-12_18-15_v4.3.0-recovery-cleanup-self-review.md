### 2. The `triggerToast` merge logic is silently broken — fix now or document?

`triggerToast` in `adminui/render.go` tries to merge new toast events with existing `HX-Trigger` header values using `json.Unmarshal`. With `encoding/json/v2`, this unmarshal silently fails (the existing value is a `jsontext.Value` that doesn't unmarshal cleanly into `map[string]jsontext.Value`). The result: two consecutive toasts overwrite each other instead of coexisting. This is a pre-existing bug I discovered while writing tests. Fix it now, or document it as a known limitation?
