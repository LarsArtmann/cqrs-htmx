## E) WHAT WE SHOULD IMPROVE

### Process
1. **Stop asking questions that ADRs already answer.** ADR-001 says Tailwind v4+. I should have just deleted admin.css without asking.
2. **Run `templ generate` before every commit.** The import grouping drifts between generator versions.
3. **Tag releases immediately after merging.** v0.5.0 sat untagged for too long while consumers were on v0.4.0.

### Architecture
4. **The count split brain persists.** Component/icon counts are hand-maintained in 4 docs. A test that asserts `README count == actual count` would prevent drift permanently.
5. **adminui inline styles.** 25 `style=` attributes across 7 .templ files. These reference CSS variables (`var(--accent)`, `var(--surface)`) which work but aren't type-checked. A templ helper or component would be cleaner.
6. **Dark mode is system-only.** adminui follows `prefers-color-scheme`. No toggle. The `.dark` class strategy from tailwind.css was removed in the consolidation — it should be re-added when a theme toggle is wanted.

### Testing
7. **No browser E2E test.** The selector bugs would have been caught instantly by a Playwright test that clicks the hamburger.
8. **No visual regression test.** Golden files test HTML structure, not rendered appearance.
