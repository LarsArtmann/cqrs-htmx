## d) TOTALLY FUCKED UP ❌

### Global sed was too aggressive

**What happened:** Used `sed -i 's/func(req testCreateUserRequest)/func(_ testCreateUserRequest)/g'` which replaced `req` → `_` in function signatures **where `req` was actually used in the body** (e.g., `req.Email`, `req.Name`).

**Files affected:** `bdd_test.go`, `coverage_test.go`, `integration_test.go` — 3 build failures with `undefined: req`.

**Root cause:** Global substitution can't distinguish between "unused parameter" and "used parameter with same name". Line-specific sed or per-edit approach is safer.

**Recovery:** Manually restored `req` parameter name in 3 locations where it was actually used in the closure body. Verified with `go test` before proceeding.

**Lesson:** For unused-parameter fixes, never use global `sed` substitution. Use line-specific addresses or the multiedit tool with exact context matching.
