05What We Should Improve

1. Integration test module lint

Fix the 2 goconst warnings in integration_test/catalog_test.go and integration_test/usermgmt_catalog_test.go. They predate this work but are the only non-zero lint in any module.

2. Re-run full nix flake check

Individual modules were verified with go test / golangci-lint, but the umbrella nix run .#test / nix run .#lint CI gate should be run end-to-end before tagging.

3. Browser verification of admin-demo

The demo code is correct and builds, but it was not launched in a real browser to visually confirm the pending → confirmed lifecycle.

4. Tailwind rebuild

Raw CSS was appended to admin-tw.css because the Tailwind CLI could not resolve @import "tailwindcss" without an npm install. When node_modules is available, regenerate admin-tw.css from tailwind.css.

5. OPFS / IndexedDB decision documentation

Phase 2 research covers the question but does not include a detailed technical spike for sqlite-wasm + OPFS in SharedWorker.

6. Rejection error UX

The rejected state shows a red border. A future polish pass could inline the actual error message from the ACK payload and auto-render a retry button.

7. Mobile sync indicator placement

The .sync-bar is in the header; on very small screens it may wrap awkwardly. Test responsive layout.

8. Command ID collision

Currently using crypto.randomUUID() in JS. Document server-side idempotency expectations if Phase 2 stores and replays command IDs.

07Top #1 Question I Cannot Figure Out Myself

Blocking Decision

Q1: Where should decide() run in Phase 2?

The engineering tradeoffs are clear (documented in ADR 0025), but the answer depends on the product/UX priority that only you can set:

  • Queue-Only gives offline write capability at very low cost, but the user won't know if a command is invalid until reconnect. Is that acceptable?
  • WASM / TS Port gives instant local validation but adds massive complexity/maintenance. Is the UX gain worth 2–4 weeks and ongoing dual-domain cost?
Need your answer to design Phase 2 correctly.
