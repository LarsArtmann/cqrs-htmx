## e) WHAT WE SHOULD IMPROVE

### Architecture

1. **Adopt CatchUpSubscriber (v3.4.0 target)** — Replace 155 LOC hand-rolled `StartProjections` with upstream `CatchUpSubscriber` + sync-wait wrapper. Gains checkpoint persistence (no full replay on restart). ADR-0031 documents the approach.

2. **Embed `command.BasicCommand` (v3.4.0 target)** — Structurally eliminates the cmdID bug class. The current approach (manual field + constructor) let 7 of 20 commands silently return zero. Embedding BasicCommand auto-mints the ID.

3. **Contribute `eventtest` fix upstream** — The `go mod tidy` breakage affects every go-cqrs-lite consumer. Either publish eventtest as a real module or remove it from the require graph.

### Testing

4. **scenario/v3 error-path support** — File an upstream issue/PR for `scenario.ThenErrorFamily(family)` or `event.Error.Is(target)` method. Unblocks BDD error-case testing.

5. **usermgmt coverage at 80.1%** — Just above the 75% gate. Gap is in OAuth2 HTTP handlers and SQL read model edge cases.

6. **OAuth2 real-provider integration test** — Only mock-based tests exist for the critical auth path.

### Developer Experience

7. **104 open TODO items** — Most are `[x]` done but not moved. A triage pass to archive completed sections would reduce noise.

8. **ROADMAP still references old version numbers** in planned sections — the "Current State" section is updated, but deeper sections still say v3.2.0/v3.3.0.
