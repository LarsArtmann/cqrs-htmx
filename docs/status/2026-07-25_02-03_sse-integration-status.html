e) What we should improve

  2. Make event mapping a single reusable function for both live and replay paths.

  4. Add an explicit Dashboard shutdown/close contract.
  5. Make EventBus subscription ownership and unsubscription explicit.
  6. Test heartbeat emission, cancellation, client disconnect, and broadcaster close.
  7. Test reconnect behavior against a real HTTP server, not only the internal channel.
  8. Fix the module/workspace/checksum issue before trusting repository-wide green status.
  9. Separate dependency-resolution failures from code failures in CI output.
  10. Add metrics or hooks for subscriber count and dropped messages where operationally important.
