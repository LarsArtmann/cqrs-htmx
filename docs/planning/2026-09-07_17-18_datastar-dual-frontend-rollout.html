06Risks & Guards

Guard

Dependency direction is an ADR decision, not a plan assumption

setup/go.mod · ROADMAP.md library principle

v1 assumed setup depends on datastar/v4. v2 defers this to ADR-0049 (F06): if the ADR picks a bridge module, M1 creates setup-datastar instead of touching setup's dependency tree. Either way, Config.DataStar (or the bridge's equivalent) defaults off — no existing consumer sees any change.

Guard

Do not publish a second SSE endpoint shape prematurely

TODO_LIST P2 · docs/planning/2026-08-30_sse-endpoint-shape-decision.md

The /sse authz posture is an open user decision. ADR-0049 (F08) must either adopt the same posture for /ds/events or hold the mount until that decision lands — never publish a shape that a later authz decision would break.

Guard

Hermetic verification only

AGENTS.md gotchas · go caches on /tmp

Workspace mode masks broken requires. Gate sweep runs GOWORK=off per module, with the /tmp cache layout (scripts/lib/go-cache-env.sh); check df /tmp before the batch.

Guard

Never hand-revert adminui/styles.css

AGENTS.md 2026-08-30 gotcha

The pre-commit hook regenerates the minified artifact; whatever it produces is canonical. Tier-4 adminui work must respect this.

Note

Commit promptly (shared tree)

AGENTS.md concurrent-sessions gotcha

An auto-git daemon commits dirty files wholesale; verify gates then commit immediately so attribution stays correct.
