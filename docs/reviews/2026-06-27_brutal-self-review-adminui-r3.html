CSRF is wired but never tested unproven claim

I wired CSRFMiddleware into the panel and demo in round 2. Every flow test (flows_test.go) POSTs without a CSRF token — because the test stack has no CSRF middleware. So I literally do not know if CSRF works. I shipped a security feature on faith.

UpdateMemberRoles is a ghost system dead code

I added Service.UpdateMemberRoles in round 1. It has zero callers in the UI. The membership table shows roles as static badges — no inline editing. A member's role can only be changed by removing and re-adding. Dead code is a lie about what the system does.

Role list is a split brain type model

The add-member form hardcodes <option value="viewer"> etc. — duplicating the Role* constants from usermgmt/authz_types.go. Add a role to usermgmt and the UI silently won't offer it. The source of truth for "which roles exist" is scattered across two files in two modules.
