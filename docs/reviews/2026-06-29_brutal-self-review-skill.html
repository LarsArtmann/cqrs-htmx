02Issue Cards

Accuracy Bug

Gotcha #7 ("Serve htmx.js yourself") is wrong for Path C

SKILL.md gotcha #7 + references/gotchas.md §1.7

My SKILL.md states universally: "Serve htmx.js yourself. There is no auto-mount; register cqrshtmx.HTMXScriptHandler()." But adminui/assets.go:40 defines func htmxScriptHandler() http.Handler { return cqrshtmx.HTMXScriptHandler() } and the panel registers it internally. Path C consumers get htmx.js for free — telling them to serve it themselves is misleading and would cause a duplicate route.

Fix Scope the gotcha: "Serve htmx.js yourself on Path A/B. Path C (adminui) serves it internally — do NOT register HTMXScriptHandler yourself when using the panel."
