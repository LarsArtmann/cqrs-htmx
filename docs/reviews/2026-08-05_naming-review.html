+

+

03Findings

Medium cfg abbreviation (553 occurrences)

Where: All modules — heaviest in dashboardui (14 files), usermgmt (12), adminui (9)

Problem: cfg is used as a parameter name for Config structs throughout. The strict Go naming guide says no abbreviations. While cfg is extremely common in Go, config is clearer for newcomers and reads better at call sites.

Fix: Find-and-replace cfg → config across parameter names. Low risk (internal parameter names, no API impact). Can be done mechanically with gofmt -r or LSP rename. Effort: S. Defer if no other reason to touch the files.
