01What the Model Does Right

The 12-problem catalog from the data-model-review skill is addressed systematically. This is not accidental — it reflects deliberate domain modeling.

+
P1 SOLVED — Branded IDs via phantom-type generics TenantID = brandid.ID[tenantBrand, string] and BotID = brandid.ID[botBrand, string] use phantom type parameters for compile-time distinction. You cannot accidentally pass a TenantID where a BotID is expected. UserID aliases go-cqrs-lite's id.UserID for cross-module interop.
+
P2 SOLVED — No pointer-as-optional-state encoding TenantState uses Suspended bool + SuspendReason string, not *time.Time as a "suspended?" flag. The state is explicit, not encoded via nil-pointer dereference risk.
+
P3 SOLVED — Constructor-enforced validation Email is a branded type (type Email string) that CANNOT be safely constructed without validation: ParseEmail(raw) normalizes, validates via mail.ParseAddress, and returns an error. The comment explicitly directs: "Use ParseEmail or MustParseEmail to construct from user input."
+
P5 SOLVED — Interface-based unions for polymorphic types SessionOrigin is an interface implemented by DirectLogin and Impersonation — a proper closed union via interface. ActorID uses a kind-discriminated struct with unexported fields (kind ActorKind, raw string) and constructor functions (NewActorID, ActorIDFromUser, ActorIDFromBot) — a closed union via encapsulation.
+
Typed string enums with Valid() — Casbin-compatible safety Action string, Effect string, and Role string are NOT naive stringly-typing. Each declares typed constants (ActionExecute, EffectAllow, RoleSuperAdmin) and a Valid() method. The string backing is justified: Casbin matches on string subjects/objects/actions, so a branded-string is the correct interop layer.
+
iota enums for closed value sets ActorKind uses iota (ActorUser = iota, ActorBot) — the correct Go pattern for a closed, ordered enum.
+
Event payloads are typed data, not behavior 21 event payload structs (UserRegisteredPayload, EmailChangedPayload, ...) are plain data with JSON tags. The fold functions (FoldUser, FoldMembership) use a type switch on evt.Type() with typed unmarshalling. This is the canonical event-sourcing pattern — events are immutable facts, not polymorphic objects.
+
Store interfaces use primitive types only WebAuthnSessionStore, VerificationTokenStore, LockoutStore, PendingTOTPStore use []byte, string, UserID — never framework types. Implementations (Redis, SQL) need not import the domain. This is dependency inversion at the type level.

02Findings — Low-Severity Polish

The domain core is clean. These findings concern types at the boundary with external systems (WebAuthn, OAuth2 providers), where the domain doesn't own the vocabulary.

Low ExternalAccountCore.Provider is plain string

Where: external_account.go

Problem: Provider string represents an OAuth2 provider name ("google", "github", "microsoft"). The set is finite but untyped — any string is accepted.

Fix: Define type Provider string with declared constants (ProviderGoogle, ProviderGitHub) and a Valid() method, matching the Action/Role pattern already in the codebase. Alternatively, keep string if the provider set is genuinely open (consumer-defined).

Low Session.Token is plain string

Where: session.go — Token string

Problem: A session token is a security primitive. Branding it (type SessionToken string) prevents accidental mixing with other string fields and signals its sensitivity.

Fix: type SessionToken string with an internal constructor. Low impact — the token is generated by generateToken() and consumed internally.

Low CredentialCore.AttestationType is plain string

Where: credential.go — AttestationType string

Problem: WebAuthn defines a finite set of attestation types ("none", "indirect", "direct", "enterprise"). Plain string accepts invalid values.

Fix: Typed string enum with Valid(), matching the Action pattern. Low priority — this struct mirrors go-webauthn's data and the validation happens in the webauthn strategy module.

Low CredentialCore.Transports is []string

Where: credential.go — Transports []string

Problem: WebAuthn authenticator transports are a finite set ("usb", "nfc", "ble", "internal", "hybrid"). Untyped slice.

Fix: type Transport string with constants. Very low priority — mirror of external protocol data.

Assessment of the findings. All four are Low severity and cluster on types that mirror external protocol data (WebAuthn, OAuth2). The domain doesn't own these vocabularies — it stores opaque data from external systems. Typing them adds safety but the real validation lives in the strategy modules (webauthn, oauth2). The domain core (User, Membership, Tenant, Bot, Session, Authz, events, commands) is exemplary.
