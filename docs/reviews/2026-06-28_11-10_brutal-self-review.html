02What Is Stupid That We Do Anyway?

JSON round-trip for form decoding

decoder.go:100-122 converts url.Values → map[string]any → JSON → struct. This is allocation-heavy, lossy, and silly when libraries like github.com/go-playground/form/v4 or github.com/gorilla/schema exist.

Two rate-limiters in one repo

Root has a token-bucket + heap LRU limiter (ratelimit_middleware.go); usermgmt has a separate fixed-window per-IP limiter (usermgmt/http.go:110-150). Different algorithms, duplicated tests, divergent behavior.

Two pagination parsers

Root has DecodePagination backed by go-cqrs-lite; usermgmt has parsePaginationParams hand-rolled in credential_http.go. Same concept, two implementations.

Manual loops instead of stdlib helpers

adminui/util.go:96 and usermgmt/http.go:29 manually check role membership; examples/basic/main.go:95,99 and usermgmt/credential_http.go:110 manually clamp ints. slices.Contains and min() have existed for a while.

adminui bypasses root CQRS dispatch

adminui handlers call *usermgmt.Service directly. The admin-demo ACK middleware therefore wraps HTTP status, not actual CQRS dispatch results. We built an honest-UI protocol but the demo does not exercise it through the library's main App.Command path.

context.TODO() in production test

usermgmt/readmodel_test.go:107 uses context.TODO() where context.Background() is intended. Tiny, but a smell.

04Ghost Systems (Existing but Unwired)

Ghost

Bot HTTP API

usermgmt/service_bot.go and api_token_middleware.go expose bot registration / token resolution, but AuthHandler.RegisterRoutes does not mount any bot endpoints. The code is usable only through direct service calls.

Ghost

Impersonation HTTP API

usermgmt/service_impersonation.go exports BeginImpersonation / EndImpersonation, but no HTTP handlers or routes exist. The session middleware stores origin info, yet nothing initiates/terminates impersonation.

Ghost

Actor / Impersonator context bridge

Root context.go provides WithActorID / WithImpersonatorID. usermgmt/middleware.go documents the bridge. No example, admin-demo, or adminui actually wires usermgmt.ImpersonatorIDFromRequest into cqrshtmx.WithImpersonatorID; the helpers are only used in root tests.

Ghost / Deprecated

ClientIP

FEATURES.md marks ClientIP PARTIALLY_FUNCTIONAL and deprecated. It is still exported, creating lingering surface area.

07Type Model & Architecture Improvements

ActorID unification

Root ActorID is a plain string. usermgmt has a rich kind-discriminated struct. The real fix is a shared identity module both can import, or at least conversion helpers in integration_test/adminui. This is the biggest type-model debt.

Branded CommandID

CommandAck.CommandID is a raw string. A small branded type (or even a type alias) would prevent accidental mixing with correlation/request IDs and make the ACK protocol more type-safe.

Email value type in event payloads

usermgmt/email.go already has a validated Email type, but legacy event payloads use raw string for backward compatibility. The next major version should use Email with an upcaster.

Use stdlib first

slices.Contains, min, max, slices.IndexFunc, and maps can eliminate several manual loops without adding dependencies.
