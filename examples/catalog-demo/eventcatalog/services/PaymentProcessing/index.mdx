## Overview

Settles placed orders. The payment.settle command is DERIVED from
order.created by the bus deriver (ADR-0154); only the read model
and the event journal ever see settlement happen.

## Relationships

- ListensFrom **OrderService** with events `order.created`
- EmitsTo **Fulfillment** with events `payment.settled`
